It reads the codes already on the page

Open any page with a QR code and click the toolbar button. You get every code on that page, not just the first one, with the decoded text in front of you.

Codes inside an image, inside a canvas, or set as a CSS background are all read from the original picture rather than from a screenshot, so small codes still come out clean.

When a code is not on the page, draw a box

Click Select an area and drag a box around anything on screen. That reaches codes a page scan cannot, like a frame of a video or a code inside a PDF viewer.

Press Escape to cancel a selection.

It never opens a link by itself

A QR code can point anywhere, so this one shows you the address and waits. Nothing is followed automatically and there is no countdown. You click when you are ready.

Decoding happens on your device. There is no account and no server, and history stays off until you switch it on in settings.
